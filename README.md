\# Comment Classifier



fullstack-проект: классификатор комментариев, который разделяет

отзывы на положительные и отрицательные. Пользователь регистрируется,

входит в приложение, отправляет комментарий на анализ и получает результат.

История запросов сохраняется, каждый пользователь видит только свои записи.



\## О проекте



Задача — упростить первичную оценку потока отзывов. Вместо ручного

разбора пользователь отправляет текст и сразу получает вердикт:

положительный отзыв или отрицательный. Авторизация нужна, чтобы история

запросов не была общей и оставалась привязана к конкретному аккаунту.



Приложение строится постепенно, по лабораторным работам курса. На текущем

этапе реализован интерфейс на демонстрационных данных; серверная часть

и база данных появятся позже.



\## Пользовательские сценарии



Неавторизованному пользователю доступны главная страница, регистрация

и вход. После входа открываются классификатор, история запросов, просмотр

отдельной записи и профиль.



Основной сценарий: пользователь вводит комментарий, нажимает кнопку

и получает результат — тональность и оценку уверенности. Запись

автоматически добавляется в историю, откуда её можно открыть подробнее

или удалить. В истории предусмотрен фильтр по тональности.



Отдельно продуманы ошибки: пустой или слишком длинный комментарий

не проходит валидацию, при неверном логине или пароле выводится понятное

сообщение, попытка открыть чужую запись отклоняется.



\## Экраны



| Маршрут         | Экран             | Доступ                |

|-----------------|-------------------|-----------------------|

| `/`             | Главная           | Публичный             |

| `/login`        | Вход              | Публичный             |

| `/register`     | Регистрация       | Публичный             |

| `/classify`     | Классификатор     | Только авторизованные |

| `/history`      | История запросов  | Только авторизованные |

| `/history/:id`  | Детали записи     | Только авторизованные |

| `/profile`      | Профиль           | Только авторизованные |

| `\*`             | 404               | Публичный             |



\## Стек



Frontend: React, TypeScript, Vite. UI-компоненты — MUI. Маршрутизация —

React Router, работа с HTTP — axios.



Backend (появится на второй лабораторной): Python, FastAPI, PostgreSQL,

SQLAlchemy.
